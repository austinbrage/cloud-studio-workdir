# Create an Admin User and set Billing alarm to monitor AWS charges

![Terraform](https://img.shields.io/badge/Terraform-%235835CC.svg?style=for-the-badge&logo=terraform&logoColor=white)
![AWS](https://img.shields.io/badge/AWS-%23FF9900.svg?style=for-the-badge&logo=amazon-aws&logoColor=white)

This project is made for recent created AWS accounts and combines two Terraform configurations:
1. **IAM User Creation**: Creates an IAM user with **AdministratorAccess** permissions and generates a secure login profile.
2. **Billing Alerts**: Sets up CloudWatch alarms to monitor AWS estimated charges and sends notifications via Amazon SNS when charges exceed a specified threshold.

## To Be Considered

This Terraform script is designed to be executed using the credentials of the AWS **root user**. The root user is required because it has the necessary permissions to manage billing alerts and create IAM users with **AdministratorAccess** permissions.

- **Important**: After running this script, it is highly recommended to deactivate the root user credentials and transition to using the newly created IAM user or another IAM user with appropriate permissions for ongoing management. This aligns with AWS security best practices.

## Prerequisites

### For Billing Alerts
To enable the monitoring of estimated charges:
1. Open the AWS Billing and Cost Management console at [https://console.aws.amazon.com/costmanagement/](https://console.aws.amazon.com/costmanagement/).
2. In the navigation pane, choose **Billing Preferences**.
3. Under **Alert preferences**, choose **Edit**.
4. Select **Receive CloudWatch Billing Alerts**.
5. Select **Receive Free Tier Usage Alerts** (on new accounts).
6. Click on **Update**.

Additionally, after applying the Terraform code, you will receive an email to confirm your subscription to the SNS topic. You must confirm this subscription to start receiving billing notifications.

## Password Management

After the Terraform script creates the new IAM user, it generates a secure password for console access. However, for security reasons, you should immediately change this auto-generated password in the AWS console. Below are the steps to reset the password:

1. On the IAM console of the ROOT USER, go to **Users** and select the created user.
2. Navigate to the **Security credentials** tab.
3. Under **Console sign-in**, click on **Manage console access**.
4. On the **Reset password** page, click on **Custom password**, type a new one, and confirm.

To retrieve the initial password generated by Terraform, use the following command since the output is set with `sensitive = true`:
```bash
terraform output -raw password
```

## Key Features

### Billing Alerts
- **Customizable Threshold**: Set a custom billing threshold (in USD) to trigger the alarm.
- **Flexible Notification**: Configure an email address to receive billing alerts via Amazon SNS.
- **Configurable Period**: Define the evaluation period (in seconds) for monitoring estimated charges.
- **Currency Support**: Supports multiple currencies for billing metrics (default is USD).
- **Evaluation Periods**: Control how many consecutive periods must breach the threshold before triggering the alarm.
- **Fully Automated**: Automates the setup of CloudWatch alarms and SNS notifications without manual intervention (except for enabling billing alerts initially).

### IAM User Creation
- **IAM User Creation**: Creates a new IAM user with a customizable name.
- **AdministratorAccess Policy**: Attaches the **AdministratorAccess** policy to the user, granting full AWS access.
- **Auto-Generated Password**: Generates a secure password for the user, which can be retrieved as a sensitive output.

This project is ideal for teams managing AWS environments who need to quickly provision administrative users with proper access controls and tagging standards.
